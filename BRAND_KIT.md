**Wall:** MGP only

**Internal ops:** MGP / Maximum Growth Partners ok in vault docs  
**New skins:** marked **proposed skins / DBA candidates** — not filed legal entities

---

## How to use this kit

1. Pick brand per touch from `CALENDAR-10-MONTH.md` / `sequences.json`.
2. Apply voice + disclaimer for that brand — never mix DAG formality with BDN casual in the same body.
3. From-domain and from-name must match `brand-registry.json`.
4. If a legal tripwire appears mid-nurture (suit, bank levy, account freeze, PG enforcement), **pause soft skins** and route to DAG content or human counsel — do not dual-brand.

## D. When to use which brand in the drip (quick matrix)

| Intent of touch | Prefer |
|-----------------|--------|
| Empathy / “daily ACH pain” | Merchant Relief Desk, BDS |
| MCA mechanics education | Business Debt Ninjas, Cashflow Clarity Co. |
| Options / fit / review | MCA Debt Advisors, Settlement Path Advisors |
| Scenario / case-study thinking | Ledger Reset Lab, BDN |
| Legal risk / suits / UCC / judgment | **DAG Law only** |
| Hard enrollment CTA | BDS or Settlement Path Advisors |
| Partner / ISO | Level Set Partners, BDS (partner mode), Clarity (math), **Fintrilo** (funding+processing capacity) |
| Unified funding + processing / Liaison Officer | **Fintrilo** |
| Soft reengage | Merchant Relief Desk, BDN, SPA |
| Hard-money / another-advance education | Advance Alternatives Brief, Stack Literacy Co. |
| Daily ACH / NSF draft pressure | ACH Breath Room, Merchant Relief Desk |
| Acute 72-hour crisis | Merchant Crisis Brief → DAG if legal tripwire |
| ISO / broker handoff hygiene | ISO Care Desk, Level Set Partners |
| Stacking mechanics literacy | Stack Literacy Co., Business Debt Ninjas |

**Umbrella line (optional in PS):** *Part of the Debt Empire network of merchant debt brands.* — use sparingly; never claim one legal entity across law + non-law.
